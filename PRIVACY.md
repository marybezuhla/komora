# Приватність · Privacy

## Українською

Комора не має акаунтів, аналітики, реклами чи звітів про збої. Вона нічого не надсилає про вас чи ваш телефон.

**Куди Комора звертається.** Лише до GitHub і лише через захищене зʼєднання (HTTPS): `api.github.com`, `github.com`, сервери файлів випусків GitHub і, для знімків екрана, `raw.githubusercontent.com`. Інших адрес у коді немає, перенаправлення на інші сайти відхиляються.

**Що бачить GitHub.** Адресу (IP) телефона, коли Комора питає:
- про нові версії застосунків — коли ви відкриваєте Комору й, якщо ввімкнено, раз на день у фоні (сповіщення чи автоматичні оновлення). У фоні про застосунки з інших джерел Комора питає лише тоді, коли вони встановлені, тож GitHub може бачити, які з доданих вами застосунків є на телефоні;
- про знімки екрана — коли ви відкриваєте подробиці застосунку, у якого вийшла нова версія (інакше знімки вже є на телефоні), тож GitHub може бачити, який застосунок ви переглядали;
- коли ви завантажуєте файл застосунку.

**Що зберігається на телефоні** (лише в приватній памʼяті Комори, без резервних копій і перенесення на інший телефон): налаштування (тема, мова, сповіщення, автоматичні оновлення), список доданих вами джерел із їхніми ключами, які версії вже були в сповіщенні, останні відповіді GitHub про випуски (щоб не питати знову, поки нової версії немає). Знімки екрана зберігаються в тимчасовій памʼяті Комори (до 50 МБ разом; Android може її очистити). Видалення Комори стирає все це.

**Які застосунки Комора бачить.** Застосунки зі свого списку. Якщо ви додаєте інші джерела — ще й застосунки з іконкою на головному екрані, лише щоб знати, чи встановлено доданий застосунок і яким ключем. Цей перелік Комора нікуди не надсилає й не зберігає.

**«Повідомити про помилку»** відкриває GitHub у браузері із заготовкою (назва застосунку, його версія, версія Android). Нічого не надсилається, доки ви самі цього не зробите.

**Посилання «Підтримати Україну»** відкриваються в браузері, на сайтах самих організацій. Комора не знає, чи ви по них переходили.

## English

Komora has no accounts, analytics, ads or crash reports. It sends nothing about you or your phone.

**Where Komora connects.** Only to GitHub, only over HTTPS: `api.github.com`, `github.com`, GitHub's release file servers and, for screenshots, `raw.githubusercontent.com`. There are no other addresses in the code, and redirects to other sites are refused.

**What GitHub sees.** The phone's address (IP) when Komora asks:
- about new versions — when you open Komora and, if turned on, once a day in the background (notifications or automatic updates). In the background Komora asks about apps from other sources only if they are installed, so GitHub can see which of the apps you added are on the phone;
- for screenshots — when you open the details of an app that has a new version (otherwise the screenshots are already on the phone), so GitHub can see which app was looked at;
- when you download an app's file.

**What stays on the phone** (only in Komora's private storage, never in backups or moved to another phone): settings (theme, language, notifications, automatic updates), the sources you added with their keys, which versions were already in a notification, GitHub's last answers about releases (so it is not asked again while there is no new version). Screenshots are kept in Komora's temporary storage (up to 50 MB in all; Android may clear it). Uninstalling Komora erases all of it.

**Which apps Komora can see.** The apps in its own list. If you add other sources, also apps with a home-screen icon, only to tell whether an added app is installed and with which key. Komora never sends or keeps that list.

**"Report a problem"** opens GitHub in the browser with a draft (the app's name, its version, the Android version). Nothing is sent unless you send it yourself.

**"Support Ukraine" links** open in the browser, on the organisations' own sites. Komora does not know whether you followed them.
